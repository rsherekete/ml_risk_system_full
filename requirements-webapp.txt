# Pinned to the versions the application is actually running on (captured from
# the working environment on 2026-09-18), because two of them are not
# interchangeable across majors: pandas 3.x changed enough of the frame API

# side of this tree (streamlit, jupyterlab, altair) and does NOT install the
# web application. Use this file for a server deployment.
#
#     python -m venv .venv
#     .venv/bin/pip install -r requirements-webapp.txt      # Linux/macOS
#     .venv\Scripts\pip install -r requirements-webapp.txt  # Windows
