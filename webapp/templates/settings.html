Where credentials live and what that means.

Credentials are held in the local SQLite database beside this application, in plain text. That is acceptable for a single-operator install on a trusted machine and is not acceptable on a shared host — move them to the OS keyring or a secrets manager before this is deployed anywhere other people can reach the filesystem.
