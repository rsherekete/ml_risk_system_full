Feature importance

Split counts from the final fitted model. Importance says what the model uses, not what causes P&L — a heavily-used feature can still be a proxy.

Feature groups

Four families of information, all knowable at the moment a trade opens.

Trade-intrinsic size, symbol, direction, hour, weekday, stop and target placement, risk-reward, EA flag.
Market context trailing 1h / 4h / 24h returns, 24h volatility, previous-bar flow imbalance.
Account history prior win rate, mean and dispersion of P&L, typical holding time, typical size.
Markout profile whether this client's earlier fills were followed by favourable moves.
The one rule that matters here. A trade's own post-entry markout is the outcome restated in other units — including it produces a near-perfect model that cannot be traded. Only the account's profile over earlier, already-closed trades is admissible, accumulated in close-time order and joined as-of each entry.

Validation status

What has been established, and what has not.

Walk-forward out-of-sample done Refit every {{ meta.config.refit_cadence_days }} days; scores are never in-sample.
Label purging done A trade enters training only once it has closed — its label does not exist before that.
Point-in-time routing threshold done Cutoff recomputed each day from that day's population, not a global quantile.
Feature leak guard done Outcome columns asserted absent; an out-of-sample AUC above 0.95 aborts the run.
Held-out period validation outstanding Not yet tested on a window the model has never seen. The single largest remaining risk, given how many configurations were evaluated against these days.
Live A-book economics outstanding Hedged flow is assumed to earn nothing. Real markup would improve these numbers; LP slippage would erode them.
