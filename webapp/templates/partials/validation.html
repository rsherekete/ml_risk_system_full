What this page is for

Every other screen reports what the model earned. This one asks whether that report is true. Three failures would each make the headline wrong without making it look wrong: the P&L could be double-counted by the exposure-day expansion (every screen would still agree with every other, because they read the same artefact); the model could be scored against the wrong target; or the result could hold only in an early regime. Each is checked below. Nothing here retrains — these are walk-forward scores, each produced by a model fitted only on days strictly before the day it scores.

3b. Which routing policy actually pays?

Same model, same scores — only the selection rule differs. Almost every client cohort loses to the broker, so every hedge costs expected profit: hedging is insurance, not alpha. A wide quota spends that premium on marginal cases and buys little; only genuinely confident calls pay for themselves. Ranking by expected dollars instead of probability was tested and is far worse — the largest accounts are the firm's biggest profit source, so weighting by size hedges precisely the wrong ones.

4. Is the target itself well-formed?

The target divides forward P&L by the account's own volatility, so an account with a near-zero volatility produces an enormous value that is arithmetic, not a real move. Those are counted and excluded from the AUC above rather than being averaged in.
