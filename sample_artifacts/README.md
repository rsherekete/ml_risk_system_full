# Sample artefacts

Anonymised, generated by `tools/make_sample_artifacts.py`.

Account identifiers are pseudonyms, monetary values are scaled and
jittered, countries are generic labels and dates are shifted. Nothing
here is a real client, a real position or a real amount. They exist so
a fresh deployment renders populated screens instead of empty ones.

**Do not draw conclusions from these numbers.** Copy into
`webapp/artifacts/` to use them, and replace them with output from a
real scan as soon as the deployment has database access.
